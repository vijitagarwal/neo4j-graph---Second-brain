# Security

Security is the practice of protecting systems, data, and users from unauthorized access or harm. Authentication verifies identity, while authorization decides what a user or service is allowed to do. Encryption protects data while it is in transit or at rest.

Network security depends on firewalls, intrusion detection systems, and zero-trust principles. Application security focuses on validating input, handling sessions safely, and minimizing vulnerabilities such as injection attacks. Security teams also monitor logs, audit access, and respond to incidents.

Strong security design requires balancing usability and safety. Good security practices are built into the system from the beginning rather than added later as an afterthought.
