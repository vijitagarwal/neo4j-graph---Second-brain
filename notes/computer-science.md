# Data Structures

Data structures are ways to organize and store data efficiently. Arrays store elements in contiguous memory, while linked lists connect nodes through pointers. Trees organize values hierarchically and are useful for searching and sorting. Graphs represent relationships among data points, and they are essential in social networks and routing algorithms.

## Key Concepts

- Arrays
- Linked Lists
- Trees
- Graphs
- Hash Tables

A hash table maps keys to values using a hash function, making lookups fast on average.
