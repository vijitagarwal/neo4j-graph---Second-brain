# Networking

Networking is the discipline of connecting devices and systems so they can communicate. Protocols define standard rules for transmission and data exchange. TCP ensures reliable and ordered delivery, while UDP favors speed and low overhead. IP addresses uniquely identify devices on a network.

A router forwards packets between networks, while a switch connects devices within a local network. Firewalls filter traffic and improve security, and load balancers distribute requests to backend services. DNS translates human-readable hostnames into IP addresses.

In modern systems, HTTP and HTTPS are commonly used for web communication, and TLS encrypts data in transit. Monitoring and debugging tools help diagnose connectivity issues across distributed systems.
