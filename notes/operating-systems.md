# Operating Systems

An operating system manages hardware resources and provides interfaces for programs. It schedules tasks, manages memory, and controls input and output devices. Processes are running instances of programs, and threads allow multiple execution flows within one process.

## Relationships

The kernel is the central part of an operating system. It interacts closely with the CPU, memory, and filesystems. Scheduling algorithms determine how processes receive CPU time, while virtualization allows multiple operating systems or environments to run on one machine.

Operating systems also rely on data structures such as queues, trees, and maps to manage tasks efficiently.
