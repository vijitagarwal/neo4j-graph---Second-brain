# Database Systems

Databases are used to store and retrieve structured information. Relational databases organize data into tables with strict schemas, while NoSQL databases provide flexible document or key-value storage. Transactional systems ensure atomicity, consistency, isolation, and durability, which are critical for financial and operational workloads.

Indexes speed up lookups by reducing the amount of data scanned. Joins connect records across tables, and query optimizers decide how to execute plans efficiently. In distributed environments, databases may replicate data across nodes to increase availability and resilience.

Data modeling is a core skill for database design, especially when balancing normalization, performance, and operational constraints. Caching layers often sit in front of databases to improve read latency.
